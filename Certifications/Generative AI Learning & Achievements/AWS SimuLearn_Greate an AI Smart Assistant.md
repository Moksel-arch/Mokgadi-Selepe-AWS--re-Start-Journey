I just completed **AWS SimuLearn: Create an AI Smart Assistant** (December 21, 2025). 

This hands-on simulation course was fantastic for putting generative AI into action—guiding a virtual customer through designing and building a conversational AI assistant, then implementing it live in the AWS console.

I learned:

- How to use **Amazon Bedrock** to select and configure foundation models for chat-based applications
- Building intelligent assistants with prompt engineering, session management, and integration patterns for natural conversations
- Deploying serverless components like **AWS Lambda**, **Amazon API Gateway**, and front-end hosting to create a fully functional AI smart assistant
- Applying best practices for security, scalability, and user experience in generative AI solutions
- Translating business requirements (e.g., customer support or internal tools) into practical Bedrock-powered implementations

The AI-driven customer interaction felt incredibly realistic, blending soft skills practice with technical builds. With my ML background, this solidified how to rapidly prototype and deploy production-ready gen AI apps on AWS—another empowering step in my cloud AI journey!
