## Organization of Certificates

I arranged my certificates into three clear sections to show how my learning has progressed step by step.

### 1. Cloud Practitioner & Core AWS Concepts  
These are the first trainings I completed to build a strong foundation in cloud computing.  
They cover:  
- What cloud computing is and why it’s useful  
- The main AWS services and how they work  
- How AWS billing and cost management works  
- Different job roles you can have in the cloud  
- Hands-on labs from AWS Cloud Quest: Cloud Practitioner  
This section gave me the basic knowledge I needed to understand AWS before moving into more technical topics.

### 2. AWS Cloud Quest: Role-Specific Modules  
After learning the basics, I moved on to more practical, role-based training through AWS Cloud Quest.  
These modules helped me get hands-on experience with real AWS tools in these key areas:  
- Core Security Concepts – learning how to keep cloud resources safe  
- Introduction to AWS Identity and Access Management (IAM) – controlling who can access what  
- Networking – setting up secure and efficient connections in the cloud  
- Databases in Practice – working with AWS databases like Amazon RDS  
- File Systems in the Cloud (Storage) – using AWS storage services like S3 and EFS  
These trainings taught me important technical skills that companies look for in cloud roles.

### 3. Generative AI Learning & Achievements  
This is my newest and most exciting area of learning!  
I’ve been exploring how to use Generative AI on AWS, and I completed many trainings and earned badges in:  
- AWS AI Practitioner Learning Plan  
- Generative AI for Decision Makers  
- AWS Cloud Quest: Generative AI Practitioner (including the training badge)  
- Working with Amazon Bedrock playgrounds  
- Building AI assistants and secure conversational AI  
- Using Amazon SageMaker and Amazon Q to create and understand code  
- Machine learning basics and generating code for webpages  
This section shows my growing passion for AI and how I’m preparing to work with modern cloud AI tools.

## My AWS Certification Roadmap

I’m following the official AWS certification paths to keep building my skills. Here’s my plan for the future (as of December 2025):

1. **Foundational Level**  
   - I’ve completed AWS Cloud Quest and many foundational trainings, which are great preparation for the **AWS Certified Cloud Practitioner (CLF-C02)**.  
   - Next step: Take the Cloud Practitioner exam to get my first official AWS certification.

2. **AI/Generative AI Path** (my main focus right now was finishing AI path)  
   - I’m working through the AI Practitioner learning plan and hands-on labs.  
   - Goal: Earn the **AWS Certified AI Practitioner (AIF-C01)** – this foundational AI certification will validate my knowledge of AI, ML, and generative AI on AWS.  
   - After that: Move toward more advanced AI certifications like **AWS Certified Machine Learning Engineer – Associate** or even the new **AWS Certified Generative AI Developer – Professional** when I have more experience.

3. **General Cloud Path** (for broader career options)  
   - After Cloud Practitioner: I would like to go for an Associate-level certification, probably **AWS Certified Solutions Architect – Associate (SAA-C03)** – it’s the most popular and valuable next step.  
   - Later: Explore **Developer Associate** or **SysOps/CloudOps Associate** depending on the roles I’m interested in.

I’m using free resources on AWS Skill Builder, AWS Cloud Quest, and SimuLearn to prepare – they’re really helpful and hands-on!
