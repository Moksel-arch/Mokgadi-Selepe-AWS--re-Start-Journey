I completed **AWS SimuLearn: Core Security Concepts** (December 2025).

It’s a short, hands-on AWS course that taught me the most important security basics on the platform. I learned:

- The Shared Responsibility Model in detail
- How to secure root accounts and use MFA properly
- Setting up IAM users, roles, and policies the right way
- Enabling CloudTrail, GuardDuty, and Security Hub
- Basic encryption with KMS and S3
- Protecting data with proper bucket policies and VPC security groups
- Common security best practices and how to spot misconfigurations

Quick but really useful – now I feel much more confident when locking down AWS accounts and resources. Great starting point for AWS security!
