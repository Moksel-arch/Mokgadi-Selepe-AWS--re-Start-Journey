# Cloud Practitioner & Core AWS Concepts

This folder has all the certificates and badges from my foundational AWS trainings.  
These were the first things I completed to understand how AWS and cloud computing work.

I started here because everyone needs a strong base before going into more advanced topics.

## What I Learned in This Section

- **Cloud Computing Essentials**  
  The basic ideas of cloud computing and why companies use it.

- **Job Roles in the Cloud**  
  Different jobs you can have in AWS, like architect, developer, or operations.

- **AWS Billing and Cost Management**  
  How to understand and control costs when using AWS services.

- **Cloud First Steps**  
  My very first hands-on practice with AWS through SimuLearn.

- **AWS Cloud Quest: Cloud Practitioner**  
  Hands-on labs that teach the main AWS services and how they fit together.

- **Cloud Practitioner Training Badge**  
  The official badge I earned after completing the Cloud Quest Practitioner role.

This section helped me pass the knowledge needed for the AWS Certified Cloud Practitioner exam (which I plan to take soon!).

I'm really happy I started here – it made everything else easier to understand.
