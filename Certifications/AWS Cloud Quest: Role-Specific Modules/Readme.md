# AWS Cloud Quest: Role-Specific Modules

This folder contains all the certificates I earned from the role-specific modules in AWS Cloud Quest.  
These are hands-on labs that helped me practice real AWS skills in important technical areas.

After finishing the basic Cloud Practitioner training, I moved on to these deeper topics to build stronger practical knowledge.

## What I Learned in This Section

- **Core Security Concepts**  
  How to protect AWS resources and understand basic security best practices.

- **Introduction to AWS Identity and Access Management (IAM)**  
  How to control access to AWS services – who can do what and how to keep things safe.

- **Networking**  
  Setting up virtual networks (VPC), subnets, routing, and connecting things securely in the cloud.

- **Databases in Practice**  
  Working with AWS database services like Amazon RDS and understanding how to store and manage data.

- **File Systems in the Cloud (Storage)**  
  Using AWS storage options like Amazon S3 for objects and EFS for file systems.

These modules were really helpful because they included simulations where I could build and configure things myself – just like in a real job.

I’m proud of completing these because they show I can work with key AWS services that companies use every day.
