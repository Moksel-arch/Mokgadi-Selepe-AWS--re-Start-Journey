# My Biggest Achievement: AWS re/Start Graduate


I am so happy and proud to say that I am now an official AWS re/Start Graduate (December 2025)!

This badge shows that I finished the complete AWS re/Start training program. It was a full cohort-based course with lots of hands-on labs, real-world projects, and training on professional skills like building a good resume and preparing for job interviews.

Thanks to this program, I now have the knowledge and confidence to start working in entry-level or mid-level cloud jobs. I learned so much about AWS services, cloud computing, security, networking, and even generative AI.

A big thank you to AWS re/Start for giving me this wonderful opportunity and helping me start my career in the cloud!
