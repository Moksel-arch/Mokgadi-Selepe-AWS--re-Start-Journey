I completed Introduction to AWS Identity and Access Management (IAM) (December 2025).

This was such an awesome hands-on course!

I learned:

- What IAM is and why it's one of the most important security services in AWS
- How to create and manage users, groups, roles, and policies
- The difference between IAM users, IAM roles, and IAM policies
- How to write least-privilege policies using JSON
- Best practices for securing AWS accounts and resources (like MFA, password policies, and access keys)

Now I can confidently control who can do what in AWS – a real game-changer for keeping cloud environments secure!
Super useful skill for any AWS journey.
